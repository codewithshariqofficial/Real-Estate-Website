## About

A **professional real estate website** with property listings, search filters, property details, and contact forms. Designed for real estate agencies and property listing platforms.

Built with **vanilla HTML, CSS, and JavaScript**.

---

## Features

| Feature | Description |
|---------|-------------|
| Property Listings | Browse available properties |
| Property Details | Full property information |
| Search Filter | Find properties by criteria |
| Hero Section | Attractive hero banner |
| Contact Form | Inquire about properties |
| Agent Profiles | Real estate agent cards |
| Responsive | Works on all devices |
| Clean UI | Professional real estate design |
